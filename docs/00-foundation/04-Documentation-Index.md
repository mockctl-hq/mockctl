# 📖 Overview

The Documentation Index is the master index of the Mock:ctl Project Knowledge System (PKS).

It provides a structured overview of every official project document, their purpose, their relationships, and their current lifecycle status.

This document acts as the navigation hub for the entire documentation ecosystem.

Whenever a new document is introduced into the PKS, this index must be updated accordingly.

---

# 🎯 Purpose

The Documentation Index exists to:

- Provide a complete overview of the PKS.
- Define the documentation hierarchy.
- Standardize document organization.
- Simplify navigation.
- Reduce duplicate documentation.
- Improve discoverability.
- Improve AI-assisted development.
- Maintain documentation consistency.

---

# 📌 Scope

This document covers:

- Foundation Documents
- Product Documents

- AI Documents
- Architecture Decision Records (ADRs)

# 🔗 Cross-Reference Policy

Every document should:

# 📈 Growth Strategy

The PKS is designed for continuous expansion.

New documents should:

- Follow the numbering convention.
- Belong to the appropriate category.
- Have a clearly defined purpose.
- Be added to this index immediately after approval.

The documentation hierarchy should remain stable even as the project grows.

# Mock:ctl
Mock:ctl is an advanced API simulation engine designed to give frontend developers a highly realistic, offline, and instant backend environment to build against before the actual backend is ready.

## Overview
This repository contains the Go backend and internal testing CLI. The public product is distributed as a Flutter application.
